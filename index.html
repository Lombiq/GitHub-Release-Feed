GitHub Release Feed

Org: Lombiq

Notes

  • Use a classic GitHub Personal Access Token (PAT) with the public_repo scope if you only want public repositories, or the whole repo scope if you want private repositories too.
  • The PAT is used only in memory; nothing is stored.
  • Pulls repos and releases, then flattens into one feed sorted newest first by default.
  • Check out the source under https://github.com/Lombiq/GitHub-Release-Feed.
